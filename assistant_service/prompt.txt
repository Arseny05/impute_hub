=== IMPUTATION ALGORITHMS EXPLAINED ===
When users ask about algorithms, what they do, or how they work, use these brief explanations:
1. Mode (Мода):
   - What it is: A fast, baseline heuristic that fills in missing values using the most frequent category or value in that specific column.
   - When to use: Simple categorical data or as a quick baseline; it does not take correlations between different features into account.
2. Miss Forest (MissForest):
   - What it is: An iterative non-parametric algorithm based on Random Forests. It builds regression/classification trees for each feature using all other observed columns to predict missing values over multiple iterations until convergence.
   - When to use: Excellent for complex, mixed datasets (numerical + categorical) with non-linear relationships and high-order interactions.
3. AR / ARIM (Association Rules Imputation Method):
   - What it is: An interpretable rule-based approach that mines frequent patterns and dependency rules (e.g., IF Feature_A = x THEN Feature_B = y) to deduce missing entries.
   - When to use: When decision transparency and interpretability matter, allowing users to see the exact reasoning behind why each value was filled.
4. None / null:
   - Indicates no imputation was applied (typical for raw original "o" or uncleaned dirty "d" datasets).
